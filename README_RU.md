# LUMA Visuals · 0.1.0

Самостоятельный клиентский визуальный мод для **Minecraft Java 1.21.11 / Fabric**.
Графитовые панели, мятный акцент, ступенчатые углы и собственный знак из трёх лучей.
Альтернативные палитры: Ice и Lilac. Это не копия и не официальный продукт Pulse / Really.

## Статус — прочитать первым

**Это исходный проект, а не готовый проверенный JAR.**
В среде подготовки нет доступа к серверам зависимостей Minecraft / Maven.
Полная сборка Gradle, ремаппинг и запуск в Minecraft не выполнены. После первой
сборки могут потребоваться исправления интеграции. Нет утверждения о проверенной
совместимости с сервером, Iris, Sodium или другими модами.

`preview/LUMA-preview.html` — автономный интерактивный **макет дизайна**, а не
Minecraft и не исполняемый мод. Значения HUD в нём демонстрационные. В игре
используются встроенный шрифт, иконки предметов и частицы Minecraft, поэтому
растеризация и эффекты отличаются от HTML-макета.

## Что написано в проекте

- Ватермарка LUMA VISUALS с текущим FPS и задержкой соединения, либо LOCAL.
- Координаты блоков, направление взгляда и приблизительная скорость в блоках/с.
- Клавиши движения и прыжка; индикаторы действий ATK / USE учитывают игровые назначения.
- Четыре слота брони и полосы оставшейся прочности.
- HUD живой видимой цели: имя, клиентское значение HP, плавная полоса здоровья.
  Цель берётся только из прицела / попытки атаки, на расстоянии не более 6 блоков,
  при прямой видимости; скрывается через 1,2 секунды без обновления.
- До четырёх текущих эффектов зелий с таймерами; в заголовке — число остальных.
- Клиентские частицы при попытке атаки, кольцо пыли при прыжке и необязательный след у ног.
  Искры не являются подтверждением нанесённого урона на сервере.
- Меню из трёх вкладок, переключение блоков и тем, масштаб / плотность панелей.
- Перетаскивание HUD, нормализованные позиции и автоматическое уменьшение на маленьком окне.
- Режим «Меньше движения»: отключает частицы и анимацию HP.
- Сохранение в `config/luma-visuals.json`; повреждённый конфиг резервируется.

Никаких KillAura, автокликера, ESP, сканирования скрытых сущностей, обходов античита,
телеметрии, внешних сетевых сервисов или аккаунтного лаунчера. Тем не менее **правила
сервера могут запрещать даже отдельные HUD-модули**: это не гарантия отсутствия бана.

## Получить JAR на Windows

1. Распакуй ZIP в обычную папку, не запускай сборку прямо из архива.
2. Установи **JDK 21** (не только JRE): https://adoptium.net/temurin/releases/?version=21
   Включи установку `JAVA_HOME` и добавление Java в PATH. Перезапусти терминал.
3. Открой `build.bat`. Нужен интернет: скрипт загрузит Gradle с официального сервера,
   проверит SHA-256, затем Gradle загрузит Minecraft, mappings, Loader и Fabric API.
4. Только если получено **BUILD SUCCESSFUL**, найди:
   `build/libs/luma-visuals-0.1.0+mc1.21.11.jar`.
   Файл `*-sources.jar` в `mods` класть нельзя.

Скрипт не устанавливает и не запускает Minecraft, не меняет игровые миры.
`build.bat` использует разрешение PowerShell только для своего процесса; системная
политика выполнения не меняется. Скрипты доступны для просмотра перед запуском.

## Linux / macOS

Установи JDK 21, curl и unzip, затем из папки проекта выполни `bash build.sh`.
Gradle скачивается в `.tools`. Если Gradle 9.2.1 уже установлен, можно выполнить
`gradle build` напрямую.

## Без локальной сборки: GitHub Actions

Загрузи содержимое папки проекта в **свой** GitHub-репозиторий. Во вкладке Actions
запусти `Build LUMA Visuals → Run workflow`. Если задача успешно завершится, скачай
артефакт `LUMA-Visuals-mc1.21.11`. Шаблон workflow приложен, но в рамках подготовки
этого проекта на GitHub ничего не создавалось и не запускалось.

## Установка после успешной сборки

1. Используй отдельный профиль **Minecraft Java 1.21.11**. Это не Bedrock, не Forge,
   не NeoForge и не файл ресурспака.
2. Установи Fabric Loader 0.18.1 или новее: https://fabricmc.net/use/installer/
3. Добавь **Fabric API для 1.21.11**, не для другой версии:
   https://modrinth.com/mod/fabric-api/versions?g=1.21.11
   Требуется 0.141.4+1.21.11 или новее для этой же версии игры.
4. Помести обычный JAR LUMA и JAR Fabric API в `mods` этого профиля.
5. Первый тест проведи в отдельном одиночном мире. Сначала не добавляй другие моды.

## Управление

- **Правый Shift** — открыть меню, находясь в мире.
- **Esc** — закрыть меню / вернуться из редактора.
- **HUD** — включить или отключить каждый блок.
- **Расстановка** — перетащи включённые блоки мышью; **Сброс** возвращает позиции,
  но не меняет настройки модулей; **Готово** сохраняет и возвращает в меню.
- **Эффекты** — частицы, кольцо, след и количество частиц.
- **Стиль** — палитра, размер HUD, плотность фона и меньше движения.
- Клавиша открытия меняется в обычных настройках управления Minecraft.
- Кнопки меню поддерживают Tab, Enter и пробел; перетаскивание требует мыши.
- HUD скрывается вместе с интерфейсом по F1. Экран настроек не ставит игру на паузу.

## Известные границы этой первой версии

- Это лёгкие ванильные частицы, **не** bloom / glow-шейдер, не объёмное кольцо и не настоящий blur.
- Нет 3D-плащей, ChinaHat, кастомных моделей и замены анимации рук.
- Target HUD показывает данные, доступные клиенту; отдельные серверы могут передавать их иначе.
- След заметнее в третьем лице. Настройки частиц самой игры могут уменьшить их количество.
- Плашка эффектов скрыта, когда нет зелий; HUD цели скрыт, когда нет цели. В редакторе они видны.
- Текст основного меню — русский; название клавиши открытия локализовано ru_ru/en_us.
- Расположение можно настроить поверх других блоков намеренно; автоматического предотвращения
  пересечений после ручного перетаскивания нет. Сброс возвращает непересекающийся пресет.

Проверки подготовки и инструкция проверки игры: `docs/VALIDATION.md`.
Собственный код и логотип предоставлены по MIT. Сторонние игровые файлы,
исходники Pulse / Really, платные ассеты и игровые JAR в архив не включены.
